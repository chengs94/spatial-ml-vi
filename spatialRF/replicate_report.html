Summary

This is a reproduction of (part of) the air pollution models originally done by Travis. Among the four PM2.5 sub-species in the original analysis, I choice elemental carbon (EC) to compare the performance of universal kriging (UK) versus the two spatial random forest models (pseudo-likelihood-based and nonparametric). 10-fold cross-validation (CV) was conducted, and prediction accuracy of each model was summarized below by \(R^2\).

UK PLS SpatRF (PL) SpatRF (NP)
Original 0.73 0.83 0.83
Reproduced 0.75 0.82 0.80

In terms of computation time, UK+PLS took 12.07 minutes and the two SpatRF methods took 80.43 minutes in total (I used the default parameter value or narrower parameter range as used by Travis. Considering the time needed in parameter tuning, SpatRF will take longer than this in a new analysis).

Details and variable importance measures

Universal kriging + partial least squares

Exponential covariance structure was used to fit the model. For each training/test set combination, 5-fold CV was conducted to find the best number of PLS components to include in the model. Among 4 of 5 training/test set combinations, using only the first PLS component lead to the best CV error. The figure below visualizes the loadings (averaged across the 5 CV folds) of the top 50 predictors.

Spatial random forest

The spatial basis functions were constructed using thin plate regression splines (TPRS). Variable importance was assessed by permuting the values of each predictor and looking at the reduction in prediction accuracy, averaged over the 5 training/test set combinations. In this example, SpatRF-PL and SpatRF-NP report identical importance measures for the predictors, because only two tuning parameters were considered, and both of them identified the same optimal tuning parameter. There are some similarities between the results of UK-PLS and SpatRF models in terms of predictors that are identified as ``important’’.

Questions

  • Parameter tuning for RF: many parameters; when do we use rule-of-thumbs and when do we choose via CV?
    • number of trees, minimum leaf size, maximum number of leaves, number of covariates to sample at each stage, …
  • SpatRF-NP seems to perform better in prediction than SpatRF-PL in all examples analyzed by Travis. This makes sense since prediction accuracy is the standard by which we train SpatRF-NP models. Does this mean SpatRF-NP would be a better choice for prediction problems than SpatRF-PL? What are some practical cases where SpatRF-PL would be more appropriate?
  • What is the intuition behind the fact that joint estimation (SpatRF) often outperforms two-stage procedures (RF+TPRS or TPRS+RF)?
  • Summarizing variable importance in UK+PLS when the optimal combination of components is changing for different training/test sets?
  • Anything else that should be considered in the analysis?
